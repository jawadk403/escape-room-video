# Yuri hospital ad - HQ (visually lossless, crf 12)

720x1280, 9:16, 3:25, H.264 crf 12 (no bitrate cap) + AAC 320k. ~310 MB per video.
GitHub limit is 100 MB per file, so each MP4 is packed (no compression, byte-identical) into a split 7z.

1. Download all `.7z.001 ... .7z.004` of the one you want into the same folder.
2. Extract only `.7z.001` (Android: ZArchiver, Windows: 7-Zip, Mac: Keka).

- `YURI_hospital_HQ_captioned.7z.001-004`
- `YURI_hospital_HQ_clean.7z.001-004`

(The older `YURI_hospital_FULL_QUALITY_*` files in the parent folder are the lower-bitrate version.)
